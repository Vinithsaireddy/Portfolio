## Overview

Bold and sophisticated creative portfolio with a dramatic, artistic personality. The design balances high visual impact through striking red gradients with professional minimalism. Dense typography creates visual hierarchy while maintaining clean, spacious layouts that feel both modern and timeless.

Clean grid-based layouts with generous whitespace. Content is contained within structured sections with consistent horizontal alignment. Typography creates natural visual breaks and hierarchy without relying on complex grid systems.

Uses a 8px base grid with scale: 2, 3, 4, 6, 8, 16.

## Colors
- **Whisper Gray** (#f0f0f0): Main page background, most frequent color
- **Pure White** (#ffffff): Secondary background areas, content sections
- **Ink Black** (#0a0a0a): Primary text color, high contrast reading
- **Fire Red** (#ff1e00): Primary accent color, gradient base
- **Ember Orange** (#ff3b14): Secondary accent, gradient variation

## Typography
- **Headline Font**: Breton
- **Body Font**: Inter

The typography system creates dramatic scale relationships, with Breton display fonts ranging from 16px to over 220px for maximum impact. Inter serves as the reliable body text at 16-17px with medium weights (400-600) for readability. Negative letter-spacing on large Breton text creates tighter, more impactful headlines. The weight hierarchy is restrained, primarily using 300-600 weights to maintain elegance.

## Elevation

The design uses no traditional shadows, instead relying on gradient overlays and color contrast to create depth. Visual hierarchy is established through dramatic typography scale differences and color intensity rather than elevation effects.

## Components
- **Hero Section**: Large typography display with gradient background, featuring name and tagline
- **Navigation Bar**: Horizontal navigation with social links and main menu items
- **Text Block**: Clean typography blocks with Inter font for readability
- **Gradient Background**: Dramatic red-to-black gradient overlays for visual impact

## Do's and Don'ts
- Do use dramatic typography scale differences to create visual hierarchy
- Don't add shadows or elevation effects - rely on color and typography for depth
- Do maintain high contrast between text and backgrounds for accessibility
- Don't use more than 2-3 font weights to preserve the clean aesthetic
- Do use the red accent sparingly for maximum impact
- Don't overcomplicate layouts - let whitespace and typography do the work
